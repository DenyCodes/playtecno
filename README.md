# Dropship Integration Platform

A React-based platform designed to connect product suppliers with retail partners through dropshipping. The project provides simple forms for suppliers and retailers to register and keeps the data on the client side for demonstration purposes.

## Available Scripts

### `npm start`
Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`
Launches the test runner in non-interactive mode.

### `npm run build`
Builds the app for production to the `build` folder.
